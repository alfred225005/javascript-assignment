# JavaScript Assignment

This repository contains solutions to basic JavaScript programming exercises.

## Questions Covered

1. Print numbers from 1 to 10
2. Find the sum of numbers in an array
3. Find the largest number in an array
4. Check if a number is even or odd
5. Reverse a string
6. Merge two arrays using the spread operator
7. Filter even numbers from an array
8. Use template literals
9. Convert a regular function to an arrow function
